# Migración serverless de Mujer Alerta

Documentación técnica y operativa para migrar Mujer Alerta a Cloud Run y Neon.

## Documentos

1. [Auditoría inicial](./01-auditoria-inicial.md)

## Rama de trabajo

`migracion/serverless-mujer-alerta`

## Regla operativa

No se eliminará ni sustituirá infraestructura productiva hasta completar:

- respaldo;
- migración;
- despliegue;
- pruebas funcionales;
- comparación de datos;
- validación de dominios;
- HTTPS;
- revisión de costos;
- plan de reversión.
